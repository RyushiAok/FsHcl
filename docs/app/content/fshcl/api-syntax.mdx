Computation expressions and constructors for HCL syntax nodes.

| Function | Description |
| --- | --- |
| `attr key value` | Creates an HCL attribute. |
| `blank` | Creates a blank line. |
| `block name labels` | Creates an HCL block with optional labels. |
| `blockComment lines` | Creates a block comment (`/* ... */`). |
| `comment text` | Creates a line comment (`# ...`). |
| `hcl` | HCL document computation expression. |
| `list_ name values` | Creates a list assignment, for example `patterns = [ str "a"; str "b" ]`. |
| `object_ name` | Creates an object assignment, for example `variables = { ... }`. |
| `optAttr key _arg1` | Creates an optional HCL attribute, omitted when `None`. |
| `rawLine value` | Creates an unparsed HCL line. |

## attr

```fsharp

```
