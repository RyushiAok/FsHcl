HCL value constructors and conversions.

| Function | Description |
| --- | --- |
| `bool value` | Creates an HCL boolean value. |
| `boolField key value` | Creates a boolean object field. |
| `call name arguments` | Creates an HCL function call expression. |
| `conditional condition trueExpr falseExpr` | Creates a conditional expression value. |
| `escapeString value` | Escapes a string for use as an HCL string literal. |
| `escapeTemplateString value` | Escapes a template string, preserving `${...}` and `%{...}` interpolation sequences. |
| `expr value` | Marks a string as a raw HCL expression when converting CLR or F# values. |
| `field key value` | Creates an object field. |
| `forObject keyVar valueVar collection keyExpr valueExpr` | Creates a for-object expression value, for example `{for k, v in map : k => v}`. |
| `forObjectGroup keyVar valueVar collection keyExpr valueExpr` | Creates a for-object expression value with grouping mode (`...`). |
| `forObjectIf keyVar valueVar collection keyExpr valueExpr condition` | Creates a for-object expression value with a condition filter. |
| `forTuple variable collection expr` | Creates a for-tuple expression value, for example `[for v in list : v.id]`. |
| `forTupleIf variable collection expr condition` | Creates a for-tuple expression value with a condition filter. |
| `heredoc delimiter content` | Creates a heredoc string value. |
| `heredocIndent delimiter content` | Creates an indented heredoc string value (`<<-` syntax). |
| `jsonencode value` | Creates a Terraform `jsonencode(...)` expression from a CLR or F# value. |
| `null_` | Creates an HCL null value. |
| `number value` | Creates an HCL number value from a CLR numeric value. |
| `numberField key value` | Creates a number object field. |
| `obj` | HCL object value computation expression. |
| `objField key` | Creates an object-valued field with a computation expression. |
| `ofRecord record` | Converts a record into an HCL object value. |
| `ofValue value` | Converts a record, primitive value, sequence, dictionary, or `Expr` into an HCL value. |
| `raw value` | Creates a raw HCL expression value. |
| `rawField key value` | Creates a raw expression object field. |
| `str value` | Creates an HCL string value. |
| `stringField key value` | Creates a string object field. |
| `templateStr value` | Creates a template string value (preserves `${...}` interpolation sequences). |
