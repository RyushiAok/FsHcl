HCL rendering functions.

| Function | Description |
| --- | --- |
| `defaults` | Default Terraform-style rendering options. |
| `document nodes` | Renders an HCL document with default options. |
| `join nodes` | Renders top-level nodes separated by a blank line. |
| `node value` | Renders a single HCL node with default options. |
| `withOptions options nodes` | Renders an HCL document with explicit options. |

## defaults

```fsharp
defaults
```

Default Terraform-style rendering options.

**Returns** `RenderOptions`
