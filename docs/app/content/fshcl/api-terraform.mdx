Terraform syntax helpers layered on the generic HCL DSL.

| Function | Description |
| --- | --- |
| `backend name` | Creates a `backend` block inside a `terraform` block (e.g. `backend "s3" { ... }`). |
| `check name` | Creates a Terraform `check` block. |
| `cloud` | Creates a `cloud` block inside a `terraform` block. |
| `condition_ value` | Creates a `condition` attribute (used in `validation`, `precondition`, etc.). |
| `connection` | Creates a `connection` block inside a resource or provisioner. |
| `count value` | Creates a `count` meta-argument. |
| `create_before_destroy value` | `create_before_destroy = true/false` inside a `lifecycle` block. |
| `data sourceName name` | Creates a Terraform `data` block. |
| `default_ value` | Creates a `default` attribute for a variable block. |
| `depends_on refs` | Creates a `depends_on` meta-argument from a list of references. |
| `description value` | Creates a `description` string attribute. |
| `dynamicWithIterator name forEach iterator` | Creates a Terraform `dynamic` block with a custom `iterator` name. |
| `dynamic_ name forEach` | Creates a Terraform `dynamic` block.  The computation-expression
 body becomes the inner `content` block automatically. |
| `error_message value` | Creates an `error_message` string attribute. |
| `for_each value` | Creates a `for_each` meta-argument. |
| `from_ value` | Creates a Terraform `from` expression attribute, used by `moved` and `removed`. |
| `id value` | Creates a Terraform import `id` attribute. |
| `ignore_changes refs` | `ignore_changes = [ref, ...]` inside a `lifecycle` block. |
| `ignore_changes_all` | `ignore_changes = all` inside a `lifecycle` block. |
| `import_` | Creates a Terraform `import` block. |
| `lifecycle` | Creates a `lifecycle` block. |
| `locals` | Creates a Terraform `locals` block. |
| `module_ name` | Creates a Terraform `module` block. |
| `move_` | Alias for `moved_`, useful when callers use the shorter term "move". |
| `moved_` | Creates a Terraform `moved` block. |
| `nullable value` | Creates a `nullable` boolean attribute. |
| `output name` | Creates a Terraform `output` block. |
| `postcondition` | Creates a `postcondition` block (used in `lifecycle`). |
| `precondition` | Creates a `precondition` block (used in `lifecycle`, `output`, etc.). |
| `prevent_destroy value` | `prevent_destroy = true/false` inside a `lifecycle` block. |
| `provider name` | Creates a Terraform `provider` block. |
| `provider_ ref` | Creates a `provider` meta-argument reference (e.g. `provider = aws.west`). |
| `provisioner typeName` | Creates a `provisioner` block (e.g. `provisioner "local-exec" { ... }`). |
| `removed_` | Creates a Terraform `removed` block. |
| `replace_triggered_by refs` | `replace_triggered_by = [ref, ...]` inside a `lifecycle` block. |
| `required_providers` | Creates a `required_providers` block inside a `terraform` block. |
| `required_version value` | Creates a `required_version` attribute inside a `terraform` block. |
| `resource typeName name` | Creates a Terraform `resource` block. |
| `sensitive value` | Creates a `sensitive` boolean attribute. |
| `terraform` | Creates a Terraform `terraform` block. |
| `to_ value` | Creates a Terraform `to` expression attribute, used by `import` and `moved`. |
| `type_ value` | Creates a `type` attribute (e.g. `type = string`).  Pass the HCL
 type expression as a raw string. |
| `validation` | Creates a `validation` block inside a variable block. |
| `value_ value` | Creates a `value` attribute for an output block. |
| `variable name` | Creates a Terraform `variable` block. |
